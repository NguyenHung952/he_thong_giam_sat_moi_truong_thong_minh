# 🌱 Hệ thống Giám sát Môi trường Thông minh

Prototype web dashboard mô phỏng **hệ thống giám sát môi trường thông minh**.

## 🎯 Mục tiêu

- Hiển thị dữ liệu môi trường trên giao diện trực quan
- Theo dõi trạng thái và thông số của hệ thống
- Làm nền tảng cho các ứng dụng IoT và giám sát môi trường

## 📂 Cấu trúc

```text
he_thong_giam_sat_moi_truong_thong_minh/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🛠 Công nghệ

- HTML5
- CSS3
- JavaScript
- Giao diện dashboard web

## ▶️ Chạy

Mở `index.html` bằng trình duyệt hoặc sử dụng static web server.
